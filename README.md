# ФанГолос 0.1

Личная бесплатная читалка фанфиков с разными голосами на iPhone.

- Загрузи TXT в UTF-8 или вставь текст.
- Нажми «Разделить на роли», проверь назначения реплик.
- Выбери системные голоса iOS для автора и персонажей и нажми ▶.
- Прогресс и текст сохраняются локально в браузере.

## GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
Открой https://nataliya1207.github.io/FanVoice/ в Safari и выбери «Поделиться» → «На экран Домой».

## Ограничения

Системные голоса iOS не являются голосами актрис. Фоновое воспроизведение при блокировке экрана не гарантируется. Нет экспорта аудио, EPUB/PDF и нейросетевого определения ролей. Не загружай тексты фанфиков в публичный репозиторий: приложение обрабатывает их в браузере. При очистке данных Safari локально сохранённая история может удалиться.
